# Diwali-sale-analysis
I made a project upon Diwali sale of a shop using Numpy,Pandas,Matplotlib,Seaborn in python

this project give insight on-
▪ Which gender buy more?
▪Which state have buy more or have order? etc.

The actual conlusion arise-
▪Married female of age group 26-35 yrs from UP,Maharastra and karnataka working in IT,healthcare and Aviation are more likely
to buy product like Food,Clothing and Electronic category.

From this conlusion the shop have to -
▪More prefrence to female customer.
▪More prefrence to the highest profit state states customer.
▪Some discount to the sector in which have highest profit customer.
